# Autoshop

Интернет-магазин автозапчастей на Laravel + MoonShine 4 + Autoopt API.

## Стек технологий

- PHP 8.3
- Laravel 11
- MoonShine 4
- MySQL 8.0
- Redis

## Архитектура

Controllers → Services → DTO → Suppliers API → Cache/DB
